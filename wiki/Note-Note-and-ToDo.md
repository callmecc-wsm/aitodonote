# Note Note and ToDo

随手记录一个念头或一件事。AI 定期读一遍待思考的问题，带着新的判断回来；需要本人行动的事项，到时间提醒。

## 使用方式

| 记录类型 | 例子 | 应用行为 |
| --- | --- | --- |
| 待思考 | 模型到底怎么训练？为什么组织会议让我很累？ | 读取原文与最近的补充，生成判断、依据、下一步和最多一个问题 |
| 待行动 | 找时间办理银行卡 | 按设定时间发送提醒，由本人执行并确认完成 |
| 仅记录 | 一条观察、一段感受 | 保留原文，不交给 AI 自动处理 |

**入口**：收件箱、AI 进展、设置。文字先保存，分类可以稍后修改。支持从其他 Android 应用分享文字到本应用。

**自动识别**：本地关键词给出初始分类；无法明确识别时归为「仅记录」。可手动改成「待思考」或「待行动」。本期没有使用模型做意图分类。

## 已实现范围

| 模块 | 行为 |
| --- | --- |
| 记录 | 新建、编辑、删除、搜索、类型筛选、完成、重新打开、延后一天 |
| 原文 | AI 结果作为独立事件追加，永远不改写原文 |
| 思考进展 | 保存摘要、正文、追问、来源和时间；补充背景后进入下一轮 |
| 模型 | 自填 HTTPS Chat Completions 兼容服务、模型 ID、API Key；支持连接测试 |
| 联网检索 | 可选 Tavily；每条最多 5 个检索结果，来源链接来自实际响应 |
| 自动回顾 | 每 1、3、6、12 或 24 小时；每轮最多 3 条，优先较早的记录 |
| 本地提醒 | 每 15 分钟检查一次到期事项；同条每天最多提醒一次 |
| 通知 | AI 进展按轮次合并通知；本地待办提醒；点击进入应用 |
| 备份 | Android 文件选择器导出、导入 JSON；只补入不存在的记录，不覆盖本机已有记录 |

## 推进规则

- **第一次**：没有结果的「待思考」记录进入队列。
- **产出后**：等待本人反馈，不周期性重写同一个答案。
- **继续**：补充背景、修改原文或点击「再想一步」后，重新进入队列。
- **完成**：只有本人点击「我已完成」才结束。AI 产出不等于事情完成。
- **暂停**：「明天再看」延后 24 小时；「仅记录」不进入 AI 队列。
- **并发**：生成结果时校验记录修订号。如果记录被编辑、完成或删除，旧结果不写回。
- **失败**：鉴权、配额或接口异常停止本轮后续请求，显示原因，等待修改配置或手动重试。
- **安静时段**：默认 22:00–08:00，按手机时区。自动回顾和提醒暂停；手动推进仍可执行。

## 模型与检索

**接入**：设置页填写服务地址（例如服务商提供的 `/v1` 地址）、模型 ID 和 API Key。支持 `/chat/completions` 文本接口；不承诺适配所有厂商的特殊推理参数。

**联网**：启用 Tavily 后，将该条问题前 400 字发给 Tavily 检索，再将检索摘要与该条记录的最近 6 次事件发给所配置的模型。服务密钥仅发送给对应服务。

**来源**：UI 只把检索响应内的 HTTPS URL 作为可点击来源。模型正文按纯文本显示，不执行 HTML、脚本或模型生成的链接。

**未联网**：结果明确显示「未联网检索 · 基于模型知识」。不能将其视为已经完成资料核验。

**成本**：每次推进最多一次检索与一次模型请求；每轮最多 3 条。费用计入用户自己的 API 账户。应用不内置共享密钥或订阅权益。

## 安卓运行与安装

**设备**：Android 8.0（API 26）及以上；编译和目标 API 35。APK 使用 CI 临时生成的开发测试签名。不同构建可能需要先备份、卸载旧版再安装。无需上架应用商店即可按设备允许的安装流程测试。

**提醒精度**：使用 Android WorkManager，属于可延后的后台任务，不是精确闹钟。省电策略、断网、强制停止等会影响执行时间。记录离线可用；模型需要设备联网。当前没有云端服务，手机关机时不会继续研究。

**通知**：Android 13 及以上需允许通知。未授予通知权限时，结果仍保存在应用内。

**数据**：SQLite 存原文和事件；API Key 使用 Android Keystore 的 AES-GCM 加密，应用不启用自动系统备份。导出的 JSON 不包含密钥。卸载前需导出记录。

## 验收要点

| 场景 | 预期 |
| --- | --- |
| 没有配置 AI | 能记录、搜索、分类和设置本地提醒；不伪造 AI 进展 |
| 配置模型 | 连接测试成功后可以手动推进；开启定时后后台按周期回顾 |
| 只有模型、没有搜索 | 产出带「未联网检索」标记 |
| 已开搜索 | 保留来自搜索响应的真实来源链接 |
| 生成中修改原文 | 旧结果被丢弃，新的原文保留 |
| 已有 AI 产出 | 待办仍未完成，用户可以补充或确认完成 |
| 用户选择仅记录 | 自动回顾不发送该条内容 |
| 导入旧备份 | 不覆盖更新后的本机记录 |

## 后续可扩展

| 方向 | 本期取舍 |
| --- | --- |
| 云端执行 | 当前采用手机后台回顾；需要全天可靠运行时再引入独立服务、同步和推送 |
| 多轮自主研究 | 当前每轮一次检索和一次生成；后续可加入研究计划和多次检索 |
| 语音 | 可以使用系统输入法语音转文字；暂不单独申请麦克风或接入转写服务 |
| 全局上下文 | 只读取当前问题的最近事件；暂不跨记录建立个人画像 |
